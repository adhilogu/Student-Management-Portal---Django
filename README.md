# Student Management Portal - Django

This is a **Django-based** web application for managing student information and interactions within an educational institution. It provides features for managing student records, tasks, and performance, while using a clean and modern UI.

## Features
- Student and faculty management
- On duty apply and On Duty viewing
- Searching Students and Facluty
- Role-based access control (Admin)
- Modern UI with Soft Dashboard integration
